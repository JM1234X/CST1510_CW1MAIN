# Running Week 7 in VS Code

Open this folder in VS Code, install the Python and Jupyter extensions, select a Python interpreter, then open the walkthrough or lab notebooks and choose **Run All**. For the mini-project, open the VS Code terminal in the LAB folder and run `python template.py`. The source data is in `cyber_records.txt`.

The three warm-up files are corrected. Git commit/push and a photograph of personal handwritten notes must be completed by the student.
